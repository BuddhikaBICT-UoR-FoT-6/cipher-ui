## ThemeToggle() ⇒ <code>JSX.Element</code>
Provides a toggle switch for switching between light (purple) and dark (black) themes with smooth animations

**Kind**: global function  
**Returns**: <code>JSX.Element</code> - Animated toggle button with theme icons  
**Component**:   
**Example**  
```js
<ThemeToggle />
```

## Usage in Project
This component is part of the Cipher Project React application that provides a user interface for various encryption and decryption algorithms including Caesar, ROT13, Atbash, Vigenère, and Rail Fence ciphers.
